01 · The problem

Institutional software tends to accumulate one system at a time, each with its own login, its own user store, and its own way of talking to nothing else. Every new platform makes the next integration harder. Solving that problem one pair of systems at a time doesn't scale; TRACE is the generalization of that lesson.

As the research platform ecosystem at UP Manila grows, SURI for research information, ARIA for AI-assisted support, the question is no longer how to connect two systems, but how to stop every future system from needing bespoke connections at all.

02 · What TRACE provides

Shared authentication

One identity layer for the ecosystem, so users move between platforms without re-authenticating and new platforms don't build their own user stores.

Shared services

Common capabilities extracted below the platforms, built once and reused instead of duplicated per system.

Integration capabilities

Defined ways for platforms to exchange data and workflows, so joining the ecosystem is a supported path rather than a custom project.

03 · Status

TRACE is in active development, 2025 to present. SURI and ARIA are its first tenants; the architecture is being extracted from systems already running in production rather than designed in the abstract.
